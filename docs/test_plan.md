# План тестирования — Geometric Lib

Отчет по лабораторной работе №4 «Написание Unit-тестов».

## 1. Цели и задачи тестирования

**Цель:** подтвердить корректность вычислений площади и периметра плоских фигур в библиотеке Geometric Lib и автоматизировать регрессионную проверку кода.

**Задачи:**
- разработать набор автоматизированных модульных (unit) тестов на базе стандартной библиотеки Python `unittest`;
- проверить работу функций на стандартных целых, дробных и граничных (нулевых) входных данных;
- проверить обработку некорректных типов аргументов;
- зафиксировать результаты тестирования и разместить исходный код тестов в публичном Git-репозитории.

## 2. Описание тестируемого продукта

**Geometric Lib** — библиотека на языке Python 3 для вычисления площади (`area`) и периметра (`perimeter`) базовых геометрических фигур. Продукт состоит из четырех независимых модулей:

- `circle.py` — круг (площадь и длина окружности по радиусу `r`);
- `square.py` — квадрат (площадь и периметр по стороне `a`);
- `rectangle.py` — прямоугольник (площадь и периметр по сторонам `a` и `b`);
- `triangle.py` — треугольник (площадь по основанию `a` и высоте `h`, периметр по трем сторонам `a`, `b`, `c`).

## 3. Область тестирования

В область тестирования входят все публичные функции расчетов в четырех модулях библиотеки:

| Модуль | Тестируемые функции | Тестовый класс |
| :--- | :--- | :--- |
| `circle.py` | `area(r)`, `perimeter(r)` | `CircleTestCase` |
| `square.py` | `area(a)`, `perimeter(a)` | `SquareTestCase` |
| `rectangle.py` | `area(a, b)`, `perimeter(a, b)` | `RectangleTestCase` |
| `triangle.py` | `area(a, h)`, `perimeter(a, b, c)` | `TriangleTestCase` |

## 4. Стратегия тестирования

- **Уровень тестирования:** модульное (unit) тестирование — каждая функция проверяется изолированно.
- **Вид тестирования:** функциональное (проверка соответствия математическим формулам) и негативное (передача некорректных типов данных).
- **Техники тест-дизайна:** классы эквивалентности (целые и вещественные числа), анализ граничных значений (нулевые размеры), проверка обработки исключений (`TypeError`).
- **Инструментарий:** встроенный фреймворк `unittest` (Python 3), методы проверок `assertEqual`, `assertAlmostEqual` (для чисел с плавающей точкой) и `assertRaises`.
- **Команда запуска:** `python3 -m unittest -v test_geometric_lib.py`.

## 5. Критерии приемки

Тестирование считается успешно завершенным, а продукт принятым при выполнении всех условий:
1. Покрыты тестами все 8 функций всех 4 модулей библиотеки.
2. Запущено 100% запланированных тест-кейсов (25 тестов).
3. Все тесты завершаются со статусом `OK` (`failures=0`, `errors=0`).
4. Исходный код тестов и документация опубликованы в открытом репозитории на GitHub.
